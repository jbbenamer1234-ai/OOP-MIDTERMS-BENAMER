# OOP-MIDTERMS-BENAMER

How to Compile and Run
Make sure all eight Java source files are in the same folder.
Open a terminal or command prompt in that folder.

Compile the program by entering:

javac *.java

Run the application using:

java PersonalEnergyApp
How to Use the Program
Enter your age when prompted.
Enter your sex (M or F).
Enter your height in centimeters and weight in kilograms.
Select your activity level from the available options.
View your estimated Basal Metabolic Rate (BMR).
Choose a calculation:
1 — Maintenance calories
2 — Caloric surplus
3 — Caloric deficit
If you choose surplus or deficit, enter your desired calorie adjustment.
View the calculated result.
Enter Y to perform another calculation or N to exit.

Note: Enter valid information when prompted. The program displays an error message when certain inputs are invalid. Results are estimates for general informational purposes only.
